# Tier 1 — Architecture Ablation Analysis (E1/E2)

验证双分支设计（Slow Branch + Fast Branch）的必要性，以及推理时消融 vs 训练消融的差异。

**基线**: Path B P1 iter500 (FVD 440, EPE 3.01, SSIM 0.279, CLIP 0.747, CTC 0.987, DTC 0.981, Img-50way 0.401, Vid-50way 0.377)
**评估**: 540 样本, full 14-metric

---

### 按维度分析

**像素重建**: 
- 推理时置零全面退化（FVD +697, SSIM -0.029, PSNR 低于训练版）
- iter500 在 SSIM 上追平 Path B（0.279），FVD 改善 14 单位，PSNR 全系列最优（12.66）
- iter2000 在 FVD 上大幅领先（372 vs 440, -68），但 SSIM 下降至 0.248
- 模式与 Path B 一致：训练后期出现 FVD/SSIM trade-off

**语义理解**:
- 推理时置零严重退化（CLIP -0.070, Img-50way -0.117）
- 训练版 iter2000 在语义维度全面最优：CLIP 0.763（+0.016 vs Path B）、Img-50way 0.430（+0.029）
- 去掉 slow 分支后语义理解反而提升，说明 fMRI 慢分支的语义信息可能存在冗余或约束

**时序一致性**:
- iter500 在 EPE 上最优（2.91, -0.10 vs Path B），CTC 提升至 0.988
- iter2000 的 DTC 退化（0.976 vs 0.981），但 VIFI 提升至全系列最优（0.860）
- 推理时置零在 VIFI 上最差（0.768），其余时序指标接近

**视频级分类**:
- iter500 的 Vid-50way 追平 Path B（0.377），保持视频分类能力
- iter2000 的 Vid-50way 下降（0.362, -0.015）
- 推理时置零退化严重（Vid-50way 0.296, -0.081）

### E1 综合判决

| 维度 | 推理时置零 | 训练 iter500 | 训练 iter2000 |
|------|:---:|:---:|:---:|
| 像素重建 | ❌ 严重退化 | ✅ FVD 改善, SSIM 持平 | ✅ FVD 最优, SSIM 退化 |
| 语义理解 | ❌ 严重退化 | ✅ 改善 | ✅ 全系列最优 |
| 时序一致性 | ❌ VIFI 退化 | ✅ EPE 最优 | ✅ VIFI 最优, DTC 退化 |
| 视频分类 | ❌ 严重退化 | ✅ 追平 Path B | ✅ 轻度退化 |

**核心发现**: 
1. 推理时置零完全不可行（全部 14 指标退化），训练后不仅恢复且超越 Path B
2. iter500 是均衡最优点：FVD 426, Vid-50way 追平 Path B, SSIM 追平 Path B, EPE 改善
3. iter2000 的 FVD 372 是全系列最优，但 SSIM（-0.031）和 Vid-50way（-0.015）付出代价
4. 去掉 slow 分支后，模型在多个语义指标上（CLIP, Img-50way）反而提升——fMRI 慢分支可能引入约束

| **Vid-2way ↑** | — | 0.807 | **0.906** | 0.898 |
| **Vid-50way ↑** | 0.377 | 0.069 | 0.262 | **0.294** |

### 按维度分析

**像素重建**: 
- 推理时置零几乎全面崩溃（FVD 2540, SSIM 0.202, PSNR 4.97）
- 训练大幅改善但始终无法接近 Path B：最优 FVD 857（比 Path B 差 417 单位）
- SSIM 反而提升（0.318 vs 0.279）——去掉 fast 分支后模型倾向生成更结构化的帧
- FVD 和 SSIM 之间存在"保真度 vs 结构一致性"trade-off

**语义理解**:
- 推理时置零严重退化（CLIP 0.546, Img-50way 0.266）
- 训练后有所恢复但远低于 Path B：CLIP 0.725（-0.022）, Img-50way 0.288（-0.113）
- 去掉 fast 分支（EEG 运动信息）后语义识别能力无法完全恢复

**时序一致性**:
- EPE 在推理时置零下"改善"至 2.32——实为生成静态帧的副作用
- CTC 和 DTC 同样虚高（0.998），因为帧间几乎没有变化
- 训练后 EPE 仍然较低（2.54-2.71），但 VIFI 显著低于 Path B
- 这是去掉运动分支后最典型的假象：时序指标"改善"实为模型退化为静态帧生成

**视频级分类**:
- Vid-50way 全面崩溃：推理时置零 0.069，训练最优 0.294（vs Path B 0.377）
- 视频级语义识别对运动信息有强依赖

### E2 综合判决

| 维度 | 推理时置零 | 训练 iter500 | 训练 iter2000 |
|------|:---:|:---:|:---:|
| 像素重建 | ❌ 崩溃 | ❌ FVD 大幅退化 | ❌ FVD 差 417, SSIM 改善 |
| 语义理解 | ❌ 严重退化 | ❌ 显著退化 | ❌ 轻度退化 |
| 时序一致性 | ⚠️ 虚高（静态帧）| ❌ 虚高 | ❌ 虚高 |
| 视频分类 | ❌ 崩溃 | ❌ 严重退化 | ❌ 严重退化 |

**核心发现**:
1. 去掉 fast 分支（EEG 运动信息）后模型无法正常生成视频：FVD 始终 >857
2. 训练有一定恢复（FVD 2540→857, CLIP 0.546→0.725）但无法接近 Path B
3. EPE/CTC/DTC 的"改善"是假象——退化为静态帧生成
4. 与 E1 形成鲜明对比：去掉 slow 分支后训练可超越 Path B (FVD 372)，去掉 fast 分支后训练最多 FVD 857
5. **Fast 分支（EEG 运动）是视频生成的核心驱动力，Slow 分支（fMRI 语义）是辅助而非必需**

## 4. 推理时消融 vs 训练消融

| 实验 | 推理时置零 FVD | 训练 iter500 FVD | 恢复幅度 |
|------|:---:|:---:|:---:|

| E2 (w/o Fast) | 2540 | 1071 | **-1469** (58% 恢复) |
| E8 (w/o Motion) | 2404 | — | — (仅推理时) |

- Tier 3 引导通道消融用推理时方法完全可行（模型能容忍单个通道为零）
- Tier 1 架构消融用推理时方法完全不可行（gated_fusion 对 single-branch 输入是 OOD）
- 训练后 E1 反而超越 Path B（FVD 372），E2 虽然改善但仍远不如

---

## 5. 双分支设计的核心结论

1. **Fast 分支（EEG → 运动/时序）是系统基石**：不可移除，否则 FVD 退化 2-5 倍
2. **Slow 分支（fMRI → 语义/结构）是可选的**：移除后通过训练可以补偿甚至提升性能
3. **训练对架构变更的适应能力**：E1 训练后恢复至 FVD 426，超越 Path B 440
4. **推理时消融不适用于架构层面**：与引导通道消融（Tier 3）不同，分支级消融必须重新训练
5. **当前双分支设计可能并非最优**：slow 分支的贡献被高估了，fast 分支的贡献被低估了
